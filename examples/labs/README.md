# Laboratorios actuariales

Estos laboratorios empiezan con una pregunta de producto, hacen visibles los
supuestos y terminan con verificaciones actuariales ejecutables. No son
cotizadores comerciales ni notas técnicas registrables.

## Laboratorio 01: dotal educativo 20/10

Construye un seguro dotal a 20 años con primas pagaderas durante 10 años.
Separa los valores presentes de fallecimiento y supervivencia, calcula la
prima y proyecta la reserva prospectiva.

```bash
python examples/labs/lab_01_dotal_educativo.py
```
